# NutriPill: English Presentation

By Dani, Max, William & Miguel

| File | What it is |
|---|---|
| `NutriPill.pptx` | **The presentation.** 14 animated slides with transitions and speaker notes. Open it in PowerPoint, Keynote or Google Slides, or import it into Canva. |
| `NutriPill.pdf` | A static copy for printing or as a backup. |
| `logo/` | NutriPill logos (dark text, white text, icon only) and the product jar image. |
| `source/` | Scripts that generate the deck. |

## Import into Canva
Canva → **Create a design** → **Import file** → choose `NutriPill.pptx`.
